Solar System Orrery

// PLAY IN BROWSER

An interactive, real-time orrery of the solar system — built in Unity and running right here in your browser. Drag to orbit the camera, scroll to zoom, and watch the planets trace their paths around the sun.

Unity · Real-time 3D
~18 MB · loads in your browser
INITIALISING…
Best experienced in Chrome or Edge · requires WebGL2 / WebGPU

// Controls

Left-drag to orbit · scroll to zoom · right-drag to pan. Use the fullscreen button for the full view.

// Built with

Unity, compiled to WebAssembly with a WebGPU/WebGL2 renderer. A port of a JavaScript orrery into a real engine.

// Status

Personal project, in active development. Expect rough edges — this is the playground where new ideas get prototyped.
